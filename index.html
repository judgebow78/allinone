Tentang Script

Apa itu All-in-One IT Support Bot?

Script bash otomatisasi yang terintegrasi dengan Telegram Bot API untuk remote management komputer client berbasis Ubuntu/Linux

All-in-One IT Support Bot adalah solusi komprehensif yang dirancang khusus untuk tim IT support di lingkungan korporat. Script ini mengubah Telegram menjadi remote command center yang memungkinkan administrator IT untuk melakukan pemeliharaan, diagnosa, dan perbaikan pada komputer client secara jarak jauh — tanpa perlu akses fisik ke setiap mesin.

Dengan arsitektur Server-Client berbasis SSH, bot ini dapat mengelola ratusan komputer secara paralel. Setiap fitur dirancang untuk menyelesaikan masalah IT yang paling sering dihadapi di lingkungan kantor, mulai dari pembersihan cache browser yang melambatkan kinerja, hingga diagnosa hardware yang kompleks.

Keamanan menjadi prioritas utama dengan sistem autentikasi berlapis (password bot + kredensial SSH terpisah), sesi yang expire otomatis dalam 24 jam, dan enkripsi kredensial yang tersimpan aman di server.

Cara Menggunakan Bot

4 langkah mudah untuk mulai mengendalikan IT infrastructure Anda

Start Bot

Kirim perintah /start ke bot Telegram untuk melihat menu utama dengan 11 fitur yang tersedia.

/start

Autentikasi

Masukkan password bot dengan /auth, lalu isi kredensial SSH remote (username, password, sudo password).

/auth P455w0rd

Pilih Fitur

Klik menu fitur yang diinginkan (A-K) atau gunakan command langsung seperti /fixwifi, /sysinfo, dll.

/fixwifi 192.168.222.10

Input Target & Execute

Masukkan IP address target komputer client. Bot akan otomatis connect, upload script, execute, dan kirim laporan.

192.168.222.10
